# API REST - Gestion de Commandes & Clients

Ce projet contient deux API REST développées avec **Laravel** pour la gestion de commandes et de clients.

## 📁 Structure du projet
API REST/
├── gestion-commandes/ # API Gestion des commandes (port 8000)
└── gestion-clients/ # API Gestion des clients (port 8001)

## 🚀 Prérequis

- PHP >= 8.1
- Composer
- MySQL / PostgreSQL
- Laravel 10.x
